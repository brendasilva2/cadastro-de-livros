# Sistema de Cadastro e Exposição de Livros

Aplicação web que permite gerenciamento de um catálogo de livros, permitindo o cadastro, a visualização e a exclusão de registros por meio de uma interface integrada ao banco de dados MySQL.

## Objetivo
Projeto acadêmico desenvolvido para simular uma livraria virtual. É como se o usuário tivesse uma pequena livraria em casa e quisesse catalogar os livros que tem disponíveis, cadastrar os novos e excluir aqueles que já não pretende mais ter posse. O projeto utiliza os conceitos de desenvolvimento web full stack. 

## Funcionalidades 

- Cadastro de livros
- Visualização de catálogo
- Exclusão de livros
- Armazenamento em banco de dados MySQL
